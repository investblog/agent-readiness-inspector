# seo

A **living** rule — SEO best practices shift. The snapshot below is illustrative, not
exhaustive; extend it (self-config + `./.agents/REGISTRY.md`). Do not freeze.

On-page snapshot: `alt` text, meta description, Open Graph / Twitter cards, slug,
schema.org structured data (rich snippets), `sitemap.xml` + `robots.txt`.
Weight/perf: WebP images → Core Web Vitals.

`sitemap.xml` / `robots.txt` are generated by the project's framework (most have a
sitemap integration) or kept as plain text files — reuse what the project has, not a new
tool. When guidance changes, update this rule.
