# css-practices

A **living** rule. The snapshot below is illustrative, not exhaustive; extend it as the
platform evolves (self-config + `./.agents/REGISTRY.md`). Do not treat it as frozen.

Current snapshot: nesting, `:has()`, container queries, `@starting-style`, `dvh/svh`.

Prefer modern native CSS over JS / preprocessor workarounds where browser support allows.
When you use a feature not in this list, add it here — the rule grows with practice.
