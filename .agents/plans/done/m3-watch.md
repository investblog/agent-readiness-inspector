## Goal
Расширение само перепроверяет отмеченные сайты и **сообщает о регрессе**:
проверка была pass → стала fail, либо композит упал ниже порога. Это главный
незанятый дифференциатор (рыночный скан: мониторинга нет ни у одного
конкурента-расширения; у веб-сканеров это платный тир).

DoD (ROADMAP): искусственный регресс на подконтрольном сайте порождает
нотификацию; watch переживает перезапуск браузера; уведомления не спамят.

## Архитектурные решения (до кода)

1. **Диф — чистая функция над снимками** (`src/shared/regression.ts`):
   `diffSnapshots(prev, next) → { regressions: CheckId[], improvements: CheckId[],
   compositeDelta }`. Тестируется без браузера, переиспользуется дашбордом
   (показ «что изменилось») и алертами.
2. **Что считается регрессом** (spec §7): `pass → fail` по любой скоримой
   проверке ИЛИ падение композита ниже порога (по умолчанию — просто любое
   падение уровня; порог настраивается позже). `pass → na` регрессом НЕ
   считается: это чаще смена семантики проверки, чем поломка сайта.
3. **Планировщик**: один `chrome.alarms` alarm с периодом из настроек
   (по умолчанию 24ч, минимум 1ч — ниже нет смысла и это ближе к спаму).
   `periodInMinutes` ≥ 60; alarm пересоздаётся на старте SW (Chrome может
   потерять его при обновлении расширения).
4. **Кто сканирует**: background напрямую (не страница) — дашборд может быть
   закрыт. Watch-скан идёт **последовательно**, по одному сайту, с паузой; при
   этом каждый сайт — отдельный вызов handleScan внутри одного alarm-события.
   Риск 5-минутного капа: ограничить пачку (например, 8 сайтов за срабатывание,
   курсор в storage) — лучше растянуть на несколько срабатываний, чем упереться
   в кап.
4b. **Решения по итогам ревью M3-a** (иначе M3-b наступит на них):
   - дыра `pass → na → fail` закрыта в M3-a: сравнение идёт с последним
     НЕ-`na` статусом (`diffAgainstHistory`), а не с предыдущим снимком;
   - алерт на падение уровня требует и падения композита ≥5 пунктов
     (`LEVEL_DROP_MIN_COMPOSITE_DROP`) — иначе сайт на границе полосы (65↔64)
     алертил бы каждый цикл;
   - **M3-b обязан сбрасывать `lastAlertSignature`, когда цикл не
     alert-worthy** (иначе сайт, который починился и снова сломался так же,
     навсегда замолчит). Пара «сброс + гистерезис» работает только вместе.

5. **Уведомления**: только при регрессе, только если юзер выдал `notifications`
   (optional permission, запрос по жесту из дашборда). Без разрешения watch
   всё равно работает — регресс виден в дашборде (бейдж «регресс» на строке).
   Дедуп: не уведомлять повторно об одном и том же регрессе того же сайта, пока
   он не починен (храним `lastAlertedAt` + сигнатуру регресса).
6. **Схема storage v2**: `sites[origin].watch?: boolean`, `settings.watch?:
   { intervalHours, notify }`, `watchState: { cursor?, lastRunAt? }`. Миграция
   v1→v2 добавляет отсутствующие поля (не ломает существующие данные).
7. **Приватность не меняется**: watch доступен только для сохранённых сайтов —
   история и так пишется только для них.

## Steps

1. **M3-a — диф + схема (S).** `regression.ts` с тестами (pass→fail, na-переходы,
   новые/исчезнувшие проверки, дельта композита); миграция storage v1→v2
   (watch-поля) + тесты миграции на данных v1.
   → verify: гейт; тест «данные v1 не теряются». → **reviewer → commit**.
2. **M3-b — планировщик + алерты (M).** Alarm, курсор-пачки, скан в background,
   сравнение с предыдущим снимком, нотификация о регрессе с дедупом; запрос
   `notifications` по жесту из дашборда; тогглы watch в таблице сайтов + бейдж
   «регресс» на строке; настройки интервала.
   → verify: гейт + смоук-сценарий с искусственным регрессом (подменить
   предыдущий снимок в storage и вызвать alarm-обработчик). → **reviewer → commit**.
3. Закрытие: ROADMAP/TODO, план → done.

## Риски
- Alarm ≥1ч не воспроизвести в смоуке в реальном времени — тестировать через
  прямой вызов обработчика (экспортировать `runWatchCycle` для теста).
- Уведомления в headless-Chromium не показываются — проверять через факт
  вызова API (стаб/лог), а не визуально.
- 5-минутный кап SW: пачка сайтов ограничена, курсор persists.
