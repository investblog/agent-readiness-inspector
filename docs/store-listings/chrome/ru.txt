НАЗВАНИЕ
Agent Readiness Inspector

КОРОТКОЕ ОПИСАНИЕ
Проверка сайтов на готовность к ИИ-агентам: robots.txt, llms.txt, Markdown, MCP, Content Signals. Локально, без аналитики.

ПОЛНОЕ ОПИСАНИЕ
Узнайте, что ИИ-агенты действительно могут найти, прочитать и использовать на текущем сайте.

Agent Readiness Inspector выполняет в браузере 22 проверки по открытым стандартам. В их числе robots.txt и правила для ИИ-краулеров, sitemap, llms.txt, markdown-негошиэйшн, Content Signals, Link-заголовки, Agent Skills, API Catalog, MCP Server Card, OAuth discovery, Web Bot Auth, WebMCP и новые коммерческие протоколы.

ЧТО ВЫ ПОЛУЧАЕТЕ

- Сопоставимый скор и уровень готовности
- Сырые данные для каждого вердикта
- Приоритетные готовые промпты для исправлений
- Боковую панель рядом с текущей вкладкой
- Сохранённые сайты, пакетные сканы и историю скора
- Мониторинг по расписанию с локальным списком алертов
- Опциональные уведомления о регрессах
- Опциональный скор на иконке и авто-скан, управляемые в настройках

Поскольку аудит выполняется внутри браузера, расширение может проверять staging-сайты и многие страницы за логином, недоступные внешнему сканеру. На отдельных сайтах защита cookies в браузере может ограничить доступ к сессии.

РЕМОНТНЫЕ НАБОРЫ

К проваленной проверке прилагается починка: что требует стандарт, какая правка нужна на том стеке, на который похож сайт (Cloudflare, Vercel, Netlify, nginx, Next.js), и одна команда, доказывающая, что правка сработала.

ПРИВАТНОСТЬ

Расширение обрабатывает URL и ответы сайта только для аудита. Результаты, сохранённые сайты, история, настройки и алерты остаются в локальном хранилище браузера. 301.st не получает данные сканов или историю просмотра. В расширении нет аналитики, телеметрии, рекламы и удалённого кода. Одна проверка обращается к DNS: она спрашивает публичный DNS-over-HTTPS-резолвер, публикует ли проверяемый домен записи для обнаружения агентами.

ЗАЧЕМ НУЖЕН ДОСТУП К САЙТАМ

Расширение проверяет любой выбранный вами сайт, поэтому ему нужен доступ к его заголовкам, robots.txt, sitemap и well-known-ресурсам. Оно ничего не внедряет в посещаемые страницы.

Agent Readiness Inspector независимо реализует открытые веб-стандарты и не аффилирован с Cloudflare.
