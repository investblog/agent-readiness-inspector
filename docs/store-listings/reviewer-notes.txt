SINGLE PURPOSE

Agent Readiness Inspector audits a user-selected website against open AI-agent discovery, content-access, bot-control, API, authentication, MCP, and agent-commerce standards. It reports local evidence, a readiness score, and repair guidance, and can monitor saved sites for regressions.

TEST STEPS

1. Open any regular HTTP or HTTPS page.
2. Select the extension icon. Chrome and Edge open a side panel; Firefox opens a popup and also provides a sidebar.
3. Wait for the score and check list. Expand a check to inspect evidence and copy its fix prompt.
4. Save the site, open Dashboard, and run a rescan to see local history.
5. Toggle watch for the saved site. Notifications are optional; the local monitoring inbox works without them.
6. Cloudflare Connect is optional and is not needed to review the primary functionality. It requires the reviewer's own Cloudflare Account ID and API token with URL Scanner: Edit.

PERMISSIONS

<all_urls>: Core functionality. The user can audit any HTTP or HTTPS site. The extension fetches that site's root page, response headers, robots.txt, sitemap, and well-known resources. It does not inject scripts or promotional content into visited pages.

storage: Stores settings, saved site origins, up to 50 local snapshots per saved site, up to 50 monitoring alerts, optional Cloudflare credentials, and a short-lived session score cache.

alarms: Runs scheduled rescans only for sites the user explicitly puts on watch.

sidePanel (Chrome and Edge): Displays the report beside the audited tab.

notifications (optional): Shows regression alerts after a user enables notifications. Monitoring remains usable through the local inbox when denied.

FIREFOX OPTIONAL DATA PERMISSIONS

authenticationInfo and browsingActivity are requested only when the user connects the optional Cloudflare URL Scanner integration. They cover sending the user's Cloudflare API token for verification and sending the explicitly selected target URL for an external comparison scan. Declining leaves all local features available.

DATA AND REMOTE CODE

The developer receives no scan, browsing, credential, analytics, or telemetry data. Cloudflare receives a token during verification and a target URL only for the user-initiated optional external scan. The package contains no remotely hosted code and executes no code fetched from the network.
