НАЗВАНИЕ
Agent Readiness Inspector

КОРОТКОЕ ОПИСАНИЕ
Проверка сайтов на готовность к ИИ-агентам: robots.txt, llms.txt, Markdown, MCP, Content Signals. Локально, без аналитики.

ОПИСАНИЕ
Проверяйте текущий сайт на готовность к ИИ-агентам, не покидая Microsoft Edge.

Agent Readiness Inspector выполняет в боковой панели Edge 22 проверки по открытым стандартам. Расширение показывает, что ИИ-агенты могут найти, прочитать и использовать: robots.txt и правила для ИИ-краулеров, sitemap, llms.txt, markdown-негошиэйшн, Content Signals, Link-заголовки, Agent Skills, API Catalog, MCP Server Card, OAuth discovery, Web Bot Auth, WebMCP и новые коммерческие протоколы.

ОСНОВНЫЕ ВОЗМОЖНОСТИ

- Скор и уровень готовности с сырыми данными для каждого вердикта
- Приоритетные готовые промпты для исправлений
- Боковая панель рядом с проверяемой страницей
- Сохранённые сайты, пакетные сканы и локальная история скора
- Мониторинг по расписанию и локальный список регрессов
- Опциональные уведомления, когда ранее успешная проверка ломается
- Опциональный скор на иконке и выключенный по умолчанию авто-скан

Аудит выполняется внутри Edge, поэтому расширение может проверять staging-сайты и многие страницы за логином, недоступные внешнему сканеру. На отдельных сайтах защита cookies в браузере может ограничить доступ к сессии.

РЕМОНТНЫЕ НАБОРЫ

К проваленной проверке прилагается починка: что требует стандарт, какая правка нужна на том стеке, на который похож сайт (Cloudflare, Vercel, Netlify, nginx, Next.js), и одна команда, доказывающая, что правка сработала.

ПРИВАТНОСТЬ И ДАННЫЕ

URL и ответы сайта обрабатываются только для аудита. Результаты, сохранённые сайты, история, настройки и алерты остаются в локальном хранилище расширения Edge. 301.st не получает данные сканов или историю просмотра. В расширении нет аналитики, телеметрии, рекламы и удалённого кода. Одна проверка обращается к DNS: она спрашивает публичный DNS-over-HTTPS-резолвер, публикует ли проверяемый домен записи для обнаружения агентами.

Доступ к сайтам нужен для единственной цели расширения: аудита любого HTTP- или HTTPS-сайта, который выбрал пользователь. Расширение читает заголовки и машиночитаемые ресурсы выбранного сайта и ничего не внедряет в посещаемые страницы.

Agent Readiness Inspector независимо реализует открытые веб-стандарты и не аффилирован с Cloudflare.
