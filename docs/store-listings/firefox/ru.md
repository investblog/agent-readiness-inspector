# Agent Readiness Inspector

## Краткое описание

Проверка сайтов на готовность к ИИ-агентам: robots.txt, llms.txt, Markdown, MCP, Content Signals. Локально, без аналитики.

## Описание

**Узнайте, что ИИ-агенты действительно могут найти, прочитать и использовать
на текущем сайте.**

Agent Readiness Inspector выполняет прямо в Firefox 22 проверки по открытым
стандартам:

- robots.txt, sitemap и правила для ИИ-краулеров;
- llms.txt и markdown-негошиэйшн;
- Content Signals и Web Bot Auth;
- Link-заголовки, Agent Skills и API Catalog;
- MCP Server Card, OAuth discovery и WebMCP;
- новые коммерческие протоколы для агентов.

Каждый скан содержит сопоставимый скор и уровень готовности, сырые данные для
каждого вердикта и приоритетные промпты для исправлений, которые можно передать
кодовому агенту.

Используйте попап на панели инструментов для быстрого скана или откройте тот же
отчёт в боковой панели Firefox. Сохраняйте сайты для локальной истории скора,
проверяйте несколько сайтов из дашборда и ставьте выбранные сайты на мониторинг.
Регрессы попадают в локальный список; браузерные уведомления опциональны.

Аудит выполняется внутри Firefox, поэтому расширение может проверять
staging-сайты и многие страницы за логином, недоступные внешнему сканеру. На
отдельных сайтах защита приватности и cookies в Firefox может ограничить доступ
к сессии.

### Опциональное сравнение с Cloudflare

Можно подключить собственный токен Cloudflare URL Scanner и явно запустить
внешний скан для сравнения. Перед передачей Firefox запросит опциональные
разрешения на данные авторизации и историю просмотра. Отказ не ограничивает
локальный аудит; Cloudflare можно отключить в любой момент.

### Приватность

URL и ответы сайта обрабатываются только для аудита. Результаты, сохранённые
сайты, история, настройки и алерты остаются в локальном хранилище расширения
Firefox. 301.st не получает данные сканов или историю просмотра. В расширении
нет аналитики, телеметрии, рекламы и удалённого кода.

Доступ к сайтам нужен для единственной цели расширения: аудита любого HTTP- или
HTTPS-сайта, который выбрал пользователь. Расширение ничего не внедряет в
посещаемые страницы.

Agent Readiness Inspector независимо реализует открытые веб-стандарты и не
аффилирован с Cloudflare.
